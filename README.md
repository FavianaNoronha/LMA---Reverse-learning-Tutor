# Reverse Learning Tutor (SETU) — starter

Hindi→Telugu first. The classmate ("Raju") is **knowledge-controlled**: what he knows lives in data, not in a prompt,
and a deterministic **leak filter** rejects any draft that shows knowledge he should not have.

## Layout
- `setu/schemas.py` — the 4 contracts: `Rule/Item`, `ClassmateTurn`, `CheckResult`, `LearnerRecord`
- `setu/checker.py` — checker v0 (correct / wrong / unsure; never guesses)
- `setu/leakfilter.py` — leak filter v0 (OOV, NOT_ONE_ERROR, UNKNOWN_RULE_CORRECT, ANSWER_LEAK, EXPLANATION) + bank fallback after 3 rejected drafts
- `setu/state.py` — per-learner rule state: unknown → taught → forgotten
- `data/hi_te/rules.json` — 15 draft rules, 29 items. **All `draft_unverified`: Telugu needs native-speaker review before use.**
- `data/hi_te/tests_v0.jsonl` — 50 test cases (checker 24, leak 16, planting 5, forgetting 5), generated by `scripts/make_tests_v0.py`
- `scripts/plain_prompt_leak_test.py` — baseline: how often does a plain "you are a student" prompt leak?

## Run
    pip install -r requirements.txt
    python -m pytest -q
    python scripts/plain_prompt_leak_test.py --mock                       # dry run of the script only
    python scripts/plain_prompt_leak_test.py --base-url http://HOST:8000/v1 --model google/gemma-3-12b-it --n 10

## Known limits of v0 (on purpose)
- Patterns are item-level regexes, not morphology. Replace with the Telugu analyser (LTRC / Stanza) in v1.
- The "unknown rule used correctly" check only catches the item-level correct forms.
- No `partial` verdict yet. Seen-word list is a stand-in built from studied rules.
- HI-TE-008 is a *positive-transfer control* (Hindi verbs also agree in gender), not an expected error.
