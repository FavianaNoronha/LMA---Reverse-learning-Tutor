# Reverse Learning Tutor (SETU) — starter

**Try it:** https://favianaNoronha.github.io/LMA---Reverse-learning-Tutor/ (no install, no sign-in; works on phones)
· Paper: `docs/paper/` · Video: `docs/video/` · Study pack (consent form, session script): `docs/study/` · Reviewer pack: `docs/reviewer_pack/`


Two learner groups, same system: **Hindi speakers learning Telugu** (`data/l1-hi_l2-te/`, built first) and **Telugu speakers learning Hindi** (`data/l1-te_l2-hi/`, rules still to be written). Each group uses its own language as the bridge and has its own rule book, because the mistakes differ.

The classmate ("Raju") is **knowledge-controlled**: what he knows lives in data, not in a prompt,
and a deterministic **leak filter** rejects any draft that shows knowledge he should not have.

## Layout
- `setu/schemas.py` — the 4 contracts: `Rule/Item`, `ClassmateTurn`, `CheckResult`, `LearnerRecord`
- `setu/checker.py` — checker v0 (correct / wrong / unsure; never guesses)
- `setu/leakfilter.py` — leak filter v0 (OOV, NOT_ONE_ERROR, UNKNOWN_RULE_CORRECT, ANSWER_LEAK, EXPLANATION) + bank fallback after 3 rejected drafts
- `setu/state.py` — per-learner rule state: unknown → taught → forgotten
- `setu/ledger.py` — the only place state changes: a checked correct fix teaches the classmate; `unsure` is logged but never counts
- `setu/planner.py` — ~1 in 5 turns is a **no-error turn** (classmate's sentence is correct), only for rules the classmate was already taught
- `setu/metrics.py` — copy rate (learner reproduces a planted error)
- `docs/interview_guide.md` — week-1 learner/teacher interviews
- `data/l1-hi_l2-te/rules.json` — 15 draft rules, 29 items. **All `draft_unverified`: Telugu needs native-speaker review before use.**
- `data/l1-hi_l2-te/tests_v0.jsonl` — 63 test cases (checker 26, leak 16, planting 5, forgetting 5, no-error 5, ledger 4, copy 2), generated by `scripts/make_tests_v0.py`
- `scripts/plain_prompt_leak_test.py` — baseline: how often does a plain "you are a student" prompt leak?

## Try the tutor (vertical slice)
    python -m setu.cli --learner me --mock                      # no model needed
    python -m setu.cli --learner me --base-url http://localhost:11434/v1 --model gemma3:12b   # Ollama on a Mac
    SETU_LLM=mock uvicorn app.server:app --reload               # web page at http://127.0.0.1:8000
In the CLI: /new learns a rule (answer its check item), /turn gets Raju's sentence, /none says there is no mistake, /skip N moves the clock N days so you can watch Raju forget.

Modules: `setu/session.py` (the loop), `setu/classmate.py` (Raju: model rewrites a bank sentence, leak filter decides), `setu/llm.py` (Ollama/vLLM client + mock), `setu/memory.py` (learner record + v0 recall model), `setu/coach.py` (fixed hints v0), `app/` (FastAPI + one page).

## Rule provenance
Every rule has `version`, `reviewer`, `reviewed_at`, `source`. Never edit a reviewed rule in place: bump `version`. Every classmate turn logs `rule_version`, `model`, `prompt_version`.

## Known limits of v0 (on purpose)
- Patterns are item-level regexes, not morphology. Replace with the Telugu analyser (LTRC / Stanza) in v1.
- The "unknown rule used correctly" check only catches the item-level correct forms.
- No `partial` verdict yet. Seen-word list is a stand-in built from studied rules.
- HI-TE-008 is a *positive-transfer control* (Hindi verbs also agree in gender), not an expected error.

## Demo website
```
pip install -r requirements.txt
SETU_LLM=demo SETU_DEMO=1 uvicorn app.server:app --port 8000     # mock model, guided demo button works
SETU_LLM=http://localhost:11434/v1 SETU_MODEL=gemma3:12b uvicorn app.server:app   # real Gemma via Ollama
```
Open http://127.0.0.1:8000. Left: learner view. Right: live inside view (Raju's state, the learner's recall,
each tool call Raju makes and its result, the referee's verdict, teacher queue, model calls per turn).
Raju runs as a tool-using agent by default (`SETU_AGENT=0` switches to the plain generate-and-filter path).

## Hosted (browser-only) version
`app/hosted/setu_app.html` is built by `python scripts/build_hosted.py` from `app/hosted/setu_app.template.html` and the rule bank.
It ports the checker, leak filter, tool, planner, Raju state, forgetting, study conditions and tests to JavaScript;
Raju's drafts come from a scripted stand-in for the model. Parity with Python: `python scripts/evaluate.py` then
`node scripts/js/parity_hosted.js` (needs Playwright; 185 cases, 0 mismatches on 29 Oct 2026).

## Share the website (free)
* **Easiest:** open `app/hosted/setu_app.html` (or `docs/index.html`) in any browser. It needs no server; only the fonts load from the internet.
* **Free public link (GitHub Pages):** repository Settings → Pages → Build and deployment → Source: *Deploy from a branch* → Branch: `main`, folder `/docs` → Save.
  After a minute the site is at `https://favianaNoronha.github.io/LMA---Reverse-learning-Tutor/` (the paper, video and reviewer pack are under the same address).
* **Local server for the full app with Gemma:** `SETU_LLM=http://localhost:11434/v1 SETU_MODEL=gemma3:12b uvicorn app.server:app --host 0.0.0.0 --port 8000`; people on the same Wi-Fi open `http://<your-mac-ip>:8000`.
  To show it to someone outside for a demo, a free tunnel such as `cloudflared tunnel --url http://localhost:8000` gives a temporary public link while your Mac is on.
